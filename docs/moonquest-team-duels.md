# MoonQuest Team Duels

Choose **Set up class → Team Duels**, or **Test team duels** on a saved adventure. Existing rooms and the cooperative mode keep their existing flow.

Every active learner is grouped with the opposing crew each round. Balanced teams are assigned once and saved; teachers may adjust them in the lobby. Matchups rotate each round. Unequal groups keep all learners, including a three-player duel for odd classes. If only one crew is present, learners can practise but receive no speed bonus.

The answer timer is 25 seconds. One learner can add 10 seconds for the whole class once. A correct final answer earns 100; the earliest unchanged correct answer in a match earns 20 extra. Correct unchanged answers within one second of the earliest qualify together. Changing an answer forfeits the speed bonus. AI follow-up questions earn accuracy points only. Timestamps come from the server, and retries with the same answer receipt do not create additional attempts.

Team race points are the sum of each round's points per participating learner, preventing larger teams from winning solely through numbers. Only revealed rounds contribute. Assessment marks remain separate. Opponent answers and individual results are not broadcast before the reveal. The public board shows team totals and aggregate class feedback, not individual mistakes.

Learners choose a jade/gold rabbit with a pink bow, blue scarf or golden star. This is an avatar choice, not inferred learner gender. Teacher and board screens keep independent sound/music controls; reduced-motion settings stop character movement.

At checkpoints, every active learner votes for their own crew's action. Each crew resolves its own tie once on the server; an empty vote chooses the default path. Story choices are cosmetic. End-of-game feedback includes each learner's own contribution.

Validation covers scoring ties, answer changes, missing/removed learners, unequal crews, rotating opponents, private snapshots, per-team votes, reload persistence, a complete 24-learner mission and browser journeys on desktop Chromium, WebKit, mobile and tablet viewport sizes.
